# Security Policy

## Reporting a Vulnerability

Please do **not** open a public GitHub issue for security vulnerabilities.

Use GitHub's private reporting:

1. Go to the repository "Security" tab
2. Click "Report a vulnerability"

If private reporting is not available, open a minimal issue that says "Security issue - please contact maintainers" without technical details.

## Supported Versions

Only the latest version on the default branch is supported with security fixes.

## Disclosure

We appreciate responsible disclosure. Please allow time for investigation and remediation before public disclosure.
